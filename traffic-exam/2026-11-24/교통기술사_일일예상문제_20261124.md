## [A] 교통신호·교차로

- ⭐ 근거: 기출 A02·A07 + 서울 간선 급행버스 4개 노선 시범운행(2026.11.16)

### [A-2] ★☆☆ 비교·분석형

- 📌 키워드: 선행좌회전, 직진후좌회전, 동시신호, 좌회전 현시
- 📎 법규: 도로용량편람(2023) 신호교차로편, 교통신호기 설치·관리 매뉴얼

### [A-3] ★★☆ 계산·수식형
편도 3차로 직진 차로군의 기본포화교통류율 2,200 pcphgpl, 보정계수(차로폭 0.96, 중차량 0.95, 경사 0.98, 기타 0.92), 주기 120초, 유효녹색 40초, 수요 1,500 대/시일 때 포화교통류율·용량·v/c비와 균일지체(d₁)를 산정하고 서비스수준 개선방안을 제시하시오.

- 📌 키워드: 포화교통류율, 보정계수, 용량, v/c, 균일지체
- 📎 법규: 도로용량편람(2023) 신호교차로편
- 🌐 해외: HCM 7th Ed. Ch.19
- ⭐ 근거: 계산형 고정 출제(A11·A12)
- 💡 풀이 요지: s=2,200×3×0.96×0.95×0.98×0.92≈5,427 대/시 → c=5,427×40/120≈1,809 대/시 → X=1,500/1,809≈0.83 → d₁=0.5×120×(1−0.333)²/(1−0.83×0.333)≈36.9초/대

### [A-4] ★★☆ 서술형

- 🌐 해외: HCM 7th Ed. Ch.20, MUTCD Ch.4C Warrants
- ⭐ 근거: 기출 A15 + 지방부 교차로 사고 이슈

## [B] 교통수요·계획

### [B-1] ★☆☆ 서술형
통행발생 단계의 유출·유입(Production·Attraction) 모형으로서 원단위법, 교차분류법, 회귀분석법을 설명하고, 존별 유출·유입 총량 균형화(balancing) 방법을 제시하시오.

- 📌 키워드: 통행발생, 교차분류, 회귀분석, 균형화

- 🌐 해외: ITE Trip Generation Manual 11th Ed.
- ⭐ 근거: 기출 B01 고빈도

### [B-2] ★★☆ 계산·수식형
두 경로의 통행시간 함수가 t₁=10+0.005x₁, t₂=15+0.0025x₂(분)이고 총 통행량이 4,000 대/시일 때, Wardrop 사용자균형(UE)과 시스템최적(SO) 통행배정 결과와 총 통행시간을 산정하고, 두 균형의 차이를 혼잡통행료와 연계하여 설명하시오.

- 📌 키워드: 사용자균형, 시스템최적, 한계비용, 혼잡통행료
- 📎 법규: 교통시설 투자평가지침
- 🌐 해외: Sheffi, Urban Transportation Networks
- ⭐ 근거: 전일 예고 주제(통행배정 균형모형) + 기출 B 계산형
- 💡 풀이 요지: UE: 10+0.005x₁=15+0.0025(4,000−x₁) → x₁=x₂=2,000, t=20분, 총 80,000대·분 / SO: 10+0.01x₁=15+0.005x₂ → x₁≈1,667, x₂≈2,333, 총≈79,167대·분

### [B-3] ★★☆ 비교·분석형

- 📌 키워드: 낙관편의, 참조집단예측, 수요 과다추정, 사후평가
- 📎 법규: 예비타당성조사 운용지침, 민간투자사업기본계획
- 🌐 해외: Flyvbjerg(2006) RCF, UK DfT Optimism Bias Guidance
- ⭐ 근거: 기출 B 응용 + 민자사업 수요 미달 이슈

### [B-4] ★★☆ 비교·분석형

- 📌 키워드: 화물수요, 상품기반, 차량기반, 라스트마일
- 📎 법규: 물류정책기본법, 생활물류서비스산업발전법

- ⭐ 근거: 쿠팡·CJ 물류 자동화 동향 + 지자체 물류계획

### [B-5] ★★★ 서술형
